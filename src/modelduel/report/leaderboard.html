Cómo se calcula

Cada modelo suma sus tareas, tests y costes en todos los duelos donde aparece. Se compara la proporción, no el total, para que jugar más duelos no dé ventaja. Una sola ejecución es una señal débil: mira el nº de duelos.

Para añadir resultados reales: modelduel run mis-tareas --a PROVEEDOR:MODELO --b PROVEEDOR:MODELO --out runs/duelo y copia runs/duelo/results.json a results/ con un nombre como 2026-10-02-duelo-x-y.json.
